# VNHLFL league history

A public statistics site for VNHLFL (Veckans NHL Fantasy League, played on Yahoo): every GM's
career, standings over time, an all-time table, trades and drafts, built from the league
founder's spreadsheets. The shared architecture blueprint is `../INFRASTRUCTURE.md`; this
project deliberately uses only a small part of it (see `DECISIONS.md`).

## Layout

| Path | What |
|---|---|
| `pipeline/` | Python 3.12: reads the founder's `.xlsx` files, resolves who is who, writes JSON |
| `pipeline/curation/team-aliases.csv` | Hand-made fixes for team names the resolver can't place (team names only) |
| `web/` | Angular 22 SPA that reads the JSON; all statistics are computed in `web/src/app/data/stats.ts` |
| `web/public/data/*.json` | Generated by the pipeline and committed: this is the site's content |
| `source-data/` | **Gitignored.** The raw spreadsheets, which contain real names |

## Commands

```bash
# pipeline (from pipeline/)
python -m venv .venv && .venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m vnhlfl_pipeline --source ../source-data --out ../web/public/data --strict
.venv/Scripts/python -m pytest -q; .venv/Scripts/python -m ruff check .; .venv/Scripts/python -m ruff format --check .; .venv/Scripts/python -m mypy

# web (from web/)
npm ci; npm start; npm test; npm run format:check; npx ng build
```

## Rules

- **The repo is public and shows team names only.** Never commit `source-data/`, a real name, or
  anything that maps a team to a person. The pipeline's `--names full` exists for when the founder
  has the members' consent; until then publish with the default `--names team`.
- **A GM's id is the slug of the first team name they played under**, so it never changes and
  holds no real name. A team-season is one GM in one division in one season (`2023-24:<gm>`,
  plus `@<division>` when a GM moved division mid-season).
- **Run the pipeline with `--strict`**: any warning (an unplaced trade alias, an unlinked
  replacement) must be fixed in `curation/` or the reader, never ignored.
- The JSON contract lives in `pipeline/vnhlfl_pipeline/build.py` and
  `web/src/app/data/models.ts`; change both together.
- Components format, `stats.ts` computes. New statistics get a test in `stats.spec.ts`.
- Use the design tokens in `web/src/styles.css`; no hex values in components. Check new UI at
  375 px: the page body must never scroll sideways.
- English in code, commits and docs; the UI is Swedish.

## Deploy

GitHub Pages via `.github/workflows/deploy.yml` on every push to `main` that touches `web/`.
Updating the site's data = run the pipeline, commit `web/public/data`, push.
